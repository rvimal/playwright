        ' These define the system's behavior, not provided per-run
        artifact "BRD.md" as BRD
        artifact "Prioritization_Prompts.md" as PPrompts
        artifact "Risk_Mitigation.md" as RPrompts
    }

' Relationships
' User only provides the backlog XLS
User --> BacklogInput : 1. Uploads

' The trigger to Roo Code to start the process
User --> Roo : 2. Start Backlog Analysis Task

' Roo Code gathers context from pre-configured files
Roo ..> BRD : Reads Business Requirements
Roo ..> PPrompts : Reads Prioritization Logic
Roo ..> RPrompts : Reads Pre-configured Risk Prompts

' Roo Code parses the user-provided backlog
Roo --> BacklogInput : 3. Parses Backlog Data

' Interactions with external services
Roo <--> JiraMCP : 4. Fetches Ticket Details (by ID from Backlog)
JiraMCP <--> JiraAPI : Live Data Fetch (Labels, Assignee, etc.)

Roo <--> LLM : 5. Passes Context + Parsed Data + Prompts for Analysis

' Generate final output
Roo --> ExcelOutput : 6. Exports Analyzed & Prioritized Results

' Descriptive Notes
note bottom of Roo
  Roo Code is the logic engine, handling
  file reading (XLS/MD), MCP tool orchestration,
  LLM interaction, and Excel generation,
  adhering to requirement #8 (no Python/LangChain).
end note

note right of BacklogInput
  Requirement #9: This is the only per-run
  input required from the BA/PM.
end note
